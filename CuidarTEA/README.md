# CuidarTEA — Stand Loop V06

Animatic web interativo de 55 segundos para apresentação do CuidarTEA.

## Abrir

Abra `stand_loop_v06.html` em um navegador moderno. Para uma prévia local mais consistente, execute um servidor estático na pasta `CuidarTEA/stand_loop_v06` e abra o arquivo pelo navegador.

Os controles permitem reproduzir, pausar, reiniciar e navegar na linha do tempo. Não há renderização de master neste repositório.

## Conteúdo

- `stand_loop_v06.html`, `.css` e `.js`: animatic.
- `assets/`: logomarca, QR, imagem de fundo e capturas oficiais usadas nas cenas.
